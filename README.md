About the Project

This project develops a reliability-aware multi-evidence fusion framework for forensic screening and risk ranking of public procurement records. It analyses different aspects of procurement behaviour using four evidence modules and combines their scores while considering evidence reliability.
The system generates a final risk score to prioritize records for further investigation. It is intended to support investigative review and does not independently prove that collusion has occurred.
